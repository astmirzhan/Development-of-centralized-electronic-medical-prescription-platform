# Development-of-centralized-electronic-medical-prescription-platform

## Project Overview
This project aims to develop a centralized electronic medical prescription platform to digitalize and secure the prescription process in the healthcare system. The platform eliminates the use of paper prescriptions, preventing forgery, unauthorized reuse, and the loss of medical history by patients. It provides a seamless, secure, and transparent ecosystem for doctors, patients, pharmacies, and administrative bodies.

## Problem Statement & Target Users
**Problems addressed:**
1. High risk of paper prescription forgery and unauthorized reuse of prescriptions.
2. Lack of a convenient online process for doctors to issue and track prescriptions.
3. Frequent loss of prescription history by patients.
4. Lack of centralized state control over prescription drug circulation.

**Target Users:**
*   **Doctors:** To conveniently issue digital prescriptions using Electronic Digital Signatures (EDS/ЭЦП).
*   **Patients:** To access their prescription history and present secure QR codes at pharmacies.
*   **Pharmacists:** To scan QR codes, verify the authenticity of prescriptions, and mark them as dispensed.
*   **Administrators:** To manage user roles and monitor the platform.

*   **Scope:** The MVP includes user authentication via EDS, doctor's dashboard for issuing prescriptions, patient dashboard for viewing history and QR codes, and pharmacist dashboard for scanning and dispensing. 
*   **Status:** Pre-defense stage. Architecture, requirements, and system design are completed. Active development phase initiated.

## Selected Technologies
*   **Frontend:** Next.js (Web), React Native / Expo (Mobile).
*   **Backend:** Go (Golang).
*   **Database:** PostgreSQL.
*   **Security:** Electronic Digital Signature (EDS) for document signing, JWT authentication.
*   **Infrastructure:** VPS deployment.
